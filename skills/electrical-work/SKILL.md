# 電気工事の現場の安全の決まりを読む（080・下書き）

この Skill は、日本語の安全の決まりから「守ること」「してはいけないこと」「なぜ」を取り出すときに、電気工事の言葉と作業の順番を取り違えないための下地。
ここに書いてあることを、取り出しの答えとして書き足さない。答えは、渡された文にあることだけ。

## 文の形の読み方

- 「〜しなければならない」「〜すること」→ 守ること。「〜してはならない」「〜しないこと」→ してはいけないこと
- 「〜のおそれがあるときは」「〜の場合において」→ 条件。条件はその決まりの中に残し、別の決まりにしない
- 括弧の中の「〜を除く。」→ 例外。例外を落とさない。例外を決まりの本体にもしない
- 「事業者は」で始まる文は、会社がやること。現場の人がやることに書き換えるときは、主語が変わったことを残す
- 「〜等」「〜など」は、挙げた物だけに狭めない

## 電気工事の言葉（取り違えやすいもの）

- 停電作業と活線作業は別。活線近接作業は、電気が来ている線の近くでの作業で、停電作業ではない
- 検電は「電気が来ていないことを確かめる」こと。検電器を当てる前に、検電器そのものが働くことを確かめる手順が付くことが多い
- 短絡接地は、止めた線に電気が戻っても人に流れないようにするためのもの。検電のあとに付け、作業が終わったら外す
- 開閉器の「施錠」「表示」は、ほかの人が誤って電気を入れないためのもの。札を掛けることと鍵を掛けることは別の手段
- 絶縁用保護具（手袋・袖・長靴など）と絶縁用防具（線や部品に掛ける覆い）は別のもの
- 高い所の作業の墜落制止用器具は、電気の決まりではなく高所の決まり。1 枚のカードに混ぜない
- 「低圧」「高圧」「特別高圧」は電圧の区分。決まりがどの区分の話かを落とさない

## 作業の順番（絵にするときに前後を入れ替えない）

1. 作業の前: 打ち合わせ・危ない所の確かめ・保護具の点検
2. 電気を止める: 開閉器を切る → 施錠・表示 → 検電 → 短絡接地
3. 作業
4. 戻す: 短絡接地を外す → 人がいないことを確かめる → 合図 → 電気を入れる

順番が文に書いていないときは、順番を足さない。

## なぜ（理由）の扱い

- 理由が文に書いてあれば、その理由を使う。書いていなければ、補った理由だと分かるようにする
- 電気の理由は「感電する」「やけどする」「火が出る」「機械が急に動く」のどれかに寄ることが多いが、文にない理由を決め付けない
