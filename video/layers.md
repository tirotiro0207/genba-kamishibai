# 通しの動画のレイヤーとコマの表（v4）

秒 × 30 ＝ コマ。終わりのコマは含む（次の場面の始まりの 1 つ前）。直すときは `node patch.mjs <レイヤー> <開始コマ> <終わりコマ>`。

## レイヤー（下から順に重ねる）

| レイヤー | Composition | 中身 |
|---|---|---|
| L1 地 | `L1-ground` | 白地（0:00〜0:13）・紫の地・床・机（2:56〜）・放り出しの扇の光 |
| L2 紙芝居の箱 | `L2-box` | 木の枠・扉（開く・閉まる）・光の輪（∞）・ステージライト（ライトの頭と光の丸）・「パタン」 |
| L3 枠の中の紙 | `L3-paper` | 0:00〜0:13 の白地の段・題の紙・むかしむかし・ポータルとドット・ヒアリングの紙・録画・時計・40 業種・めでたしの紙 |
| L4 床のキャラ | `L4-cast` | 主人公・相棒・リュック・案内人・職人さん・先輩・監修者・門・吹き出し・粒・ほこり |
| L5 字幕 | `L5-sub` | 下の帯の字幕・仮の札・版の札 |

- どれも 1920×1080・30 コマ・5400 コマ。L2〜L5 は透明のまま（ProRes 4444 の .mov）。L1 だけ地の色を塗る
- 置き場は `video/out/layers/<Composition>.mov`（git の外）。重ねた mp4 は `private/material/<VIDEO_TAG>/full.mp4`
- 全部を書き出す: `node render-layers.mjs`（名前を渡すとそのレイヤーだけ）。一部を直す: `node patch.mjs`
