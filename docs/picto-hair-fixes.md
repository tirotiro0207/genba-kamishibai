# 髪の直しの記録

キャラクターを作る画面の髪（おかっぱ以外の 18 種。作者が手で塗った絵を `scripts/picto-hair-trace.py` でパスにした形）を、作者の見直しで直してきた記録です。次に髪を直すときは、先に「直す前に毎回やること」を通してから始めます。製品仕様 §14。

## 直す前に毎回やること

1. **見本の下絵と重ねて測る。** 作者の見本（灰色の下絵の上に赤い髪を載せたガイド）とこちらの描画を、同じ頭の座標で半透明に重ねた絵を作って目で見る。ずれは数字で測る（顔の線の真ん中の x を下絵とこちらで比べる）
2. **指摘が同じ向きにそろっていたら、個別に直す前に置き場所を疑う。** 「後頭部がはみ出る」「前髪が出すぎ」「耳とずれる」が何種類にも出たら、1 つずつ継ぎ足さず、髪の置き方（位置合わせ）の誤りを先に探す
3. **顔の輪郭（標準の頭）は変えない。** 合わないときは髪の方を合わせる
4. **見直し表と同じ大きさと、つなぎ目の拡大の両方で見る。** 縮んだ一覧だけで「崩れていない」と言わない。線と線・灰と線の継ぎ目は 20〜25 の範囲に拡大して見る
5. 直したら、見直し表（○△× を付けられる HTML）を差し替え、各枠に何を直したかを書く

## 失敗して戻したやり方

- **とさかの縁を下へまっすぐ伸ばした線で内側を切る**: 斜め・真横の内側が消えた（線の付近の縁は線に沿って曲がるので、伸ばした線が交わってしまう）
- **線より内のとさかを、線を横切る所の左右の幅でまっすぐ切る**: 真横で、付け根が縦にすぱっと切れた段になった
- **真横のツインテールの後頭部を黒で埋める・尾を後ろへずらす**: 耳と尾の位置の関係が見本と変わった。原因は置き場所のずれで、埋める必要はなかった
- **縁の黒の帯を広く取って、とさかを取り出す**: とさかの内側の丸みまで削れて、付け根が平らな足になった
- **頭の丸みを y −30 から新しい曲線で引き直す**: 頭のてっぺんが細くとがり、モヒカンの灰が線の外へはみ出した。元の丸み（y −48 より上）は残し、つなぎ目だけを計算で足した

## 道具

- 見本の下絵との重ね絵: 下絵（作者の見本の元になった描画）の頭の位置を、パスにするときと同じ計算で求め、こちらの頭と髪を半透明の赤で重ねる。ずれは線の真ん中の x を頭の座標で比べる
- 直しの表: `scripts/picto-hair-trace.py` の `FIX`（髪と向きごとの直し）。今残っているのは前髪 2 つの `fitx` と、くせ毛の `front_all` だけ
- 見直し表: 19 種 × 3 つの向きを並べ、○△× とコメントを付けて保存できる HTML。直したら絵を描き直し、各枠の「直し」に何をしたかを書く
