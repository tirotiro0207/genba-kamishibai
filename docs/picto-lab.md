# 絵の試行錯誤の記録（API を使わない手元の試し）

絵の完成度を上げるあいだは、API を呼ばずに、作業中の Claude（Opus 5.5）と、サブエージェントの Fable 5.1 が SVG を手で書く。
撮るのは `scripts/picto-render.ts`（5 秒の動きを 30 fps で撮って動画にし、指定の秒のコマを動画から切り出す）。
良い形が決まってから、その描き方を指示文に入れて API で試す。画像と動画はリポジトリの private/picto/lab（git に入れない）。

## 2026-11-02 相談の場面（どっちを止める？ → こっちだよ）

### 出発点
- 下絵は、Opus 5.5 が API で描いた相談の 2 回目の版（作者が「キャラクターはこれがいちばん良い」とした絵柄）
- 作者の指摘: かぶり物のつばを顔の向きに付ける／手や腕を顔に重ねない・人を重ねない／施工管理に管理表を持たせる
- 2 回目の版で残った点: 聞くコマで 2 人の胴がほぼ触れる／答えるコマで新人のヘルメットが傾いて浮く／施工管理の上げた手が何も指さない

### 2 つを比べて
- 構図と答えはほぼ同じに収まった（同じ下絵と同じ指摘から始めたため）
- 違いは指す腕: Opus 版はまっすぐな腕が胴をたすきのように横切る。Fable 版は肘を曲げ、手首から先だけが管理表に届く
- 次は Fable 版の二節の腕を手本にし、Opus 版の「管理表へ目を落とす」を足すと、両方の良いところがそろう

### ミソ（指示文に入れたいこと）
1. **かぶり物は、向きを反転させる g の中で頭と同じ g に入れる。** 振り向き（scaleX(−1)）にも、うなずき・首の傾きにも、つばが一緒についてくる。ヘルメットも左右対称にせず、つばを前にだけ出す
2. **うなずきは回すより沈める。** 首の付け根を軸に 15° 回すと、つばが跳ね上がって「傾いて浮いた」ように見える。数 px 下げて 5〜6° だけ回す
3. **立ち位置は数字で決める。** 「近づく」とだけ言うと胴が触れるまで寄る。胴と胴の間（px）を決め、腕・持ち物の端まで含めて空きを確かめる
4. **手は必ず何かを指す。** 指す先（管理表の 1 行・吹き出し・盤）を座標で決め、腕の角度はそこから逆算する。空へ上げた手は意味が読めない
5. **描く順で前後を決める。** 指す腕は持ち物より後に描く（先に描くと体と板に隠れる）。重ねたくない物（顔）の上を通る経路は使わない
6. **指す腕は二節にする。** 肩の g の中に肘の g を入れ子にし、指先の目標座標から肩と肘の角度を逆算する（今回は肩 40°・肘 45°）。継ぎ目は「上腕の輪郭 → 前腕 → 上腕の中身」の順に描いて消す
7. **振り向きは一瞬で切り替える。** scaleX(−1) を時間をかけて補間すると、途中で体がつぶれた絵が出る

## 2026-11-03 相談の場面・2 回目（帽子の規格と、電線をどっちにつなげるか）

### 2 つを比べて
- 帽子の規格はどちらもそろった

- 次の手本は Fable 版 v5 にする

### ミソ（追加）
8. **かぶり物は 1 つの形を defs に置き、塗りは use の fill で変える。** 形を人ごとに書くと、同じ規格のはずが別の物に見える
9. **持ち物は人が手に持たせる。** 背景に置いただけの物は、迷っている対象に見えにくい。持つ・置くの 2 状態は 2 枚描き、振り向きの瞬間に opacity で入れ替える
10. **反転・回転の軸にする g には、見えない大きな rect を敷く。** transform-box: fill-box の大きさは、子の腕を振り上げた分まで変わり、軸がずれて体が飛ぶ

## 2026-11-03 相談の場面・5 回目（靴を足の一部にする）

### 作者の指摘
- 靴は Opus 版の大きい方ではなく、Fable 版の小さい方が良い
- ただし靴が脚の端に寄っている。脚の幅の真ん中の軸に靴を合わせて整理する
- 将来、つま先立ち・かがむ・かかとを開くなどの場面で靴が付いてくるので、足の一部として表す

### Fable 5.1（サブエージェントが手で描く）
| 回 | 直したところ | 見た結果 |
|---|---|---|
| v9 | 靴を「原点＝足首」の部品にする（かかと x −22＝脚の後ろの縁、つま先 x 38、幅の真ん中が脚の軸の少し前）／脚を もも → ひざ → すね → 足首 → 足 の 3 節の入れ子にする／確かめ用に、立つ・つま先立ち・かかと立ち・かがむ・歩きの 5 つの姿を 1 秒ずつ撮る／本編の歩く脚にも見えない rect を敷き、ずれていた股関節の軸（22px）を直す | 5 つの姿とも、靴が脚から外れず、床にめり込まず、関節に継ぎ目が出ない。本編の靴は脚の真下にそろった。つま先立ちで靴の口が斜めに脚を横切る、かかと立ちで靴が角ばる、が残る |

### 脚の作り方（手本）
- 入れ子: もも の g ＞ translate(0,85) ＞ すね の g ＞ translate(0,77) ＞ 足 の g ＞ 靴の部品
- 各 g に transform-box: fill-box と、子がどう回っても届かない見えない rect を敷き、transform-origin は rect の中心を px で書く（もも ±240 → 240px 240px、すね ±140 → 140px 140px、足 ±60 → 60px 60px）。これで軸が股関節・ひざ・足首に固定される
- 姿勢の値の例: つま先立ち＝足 +35°・体を 17px 上げる／かかと立ち＝足 −20°・体 6px 上げる／かがむ＝もも −40°・すね +65°・足 −25°（3 つの和を 0 にして靴底を床と平行に）・体を 27px 下げる

### ミソ（追加）
17. **関節は「translate で関節の位置へ → 回す g → 見えない rect で大きさを固定」の 3 段で 1 つ。** 入れ子では外側ほど rect を大きくする
18. **床に付ける姿勢は、回したあとの足の先の y から体の上げ下げを数える。** かがむときは、もも・すね・足の角度の和を 0 にすると靴底が床と平行になる
19. **部品に横へ出る形（靴など）を足したら、見えない rect を敷き直す。** 大きさが変わって回転の軸がずれる
