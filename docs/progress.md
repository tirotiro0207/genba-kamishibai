# 進み具合

`tools/progress.py` が [plan.md](plan.md) と [compass.md](compass.md) から作る（手で書かない）。作った日: 2026-11-02（日本時間）

## 軸

- **始点**: 現場のルールや安全の決まりは、文字の資料と、ベテランの頭の中にある / 外国籍の新入社員には、日本語の文字ではそれが届かない
- **終点**: 文字を読めなくても、絵のカードで「守ること」と「その理由」が分かる / 新入社員に届くのは、会社の監修者が直して署名したカードだけ
- **終点の先**: 業界: 電気工事から始めて、建設・製造・介護など、外国籍の人が働くほかの業界へ / 言葉: ベトナム語から、英語・クメール語へ
- **変化の質**: 自然な言葉や文章が、絵になる / 話した言葉や資料の文章が、ピクトグラムのカードに変わる
- **変化の量**: 膨大な情報が、ピクトグラムに収束する / 見る人が受け取る量は減るが、情報は失わない
