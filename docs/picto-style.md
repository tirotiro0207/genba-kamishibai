## 1. 人を 4 つの層に分ける

人は、変わる速さが違う 4 つの層でできています。層ごとに別々に選べるので、組み合わせで多くの人を描けます。

| 層 | 決めるもの | いつ変わるか | 例 |
|---|---|---|---|
| 体 | 骨格・関節・服の形・色の明暗 | 変わらない（全員同じ） | 胴・腕・足・靴・ベスト |
| 髪 | 髪形 | その人のもの。カードの中で変えない | おかっぱ・短い髪・お団子 |
| かぶり物 | 種類と、かぶっているかどうか | 職場で種類が決まり、場面でかぶる・外すが変わる | 安全帽・つばの帽子・コック帽・衛生キャップ |
| 役 | 新人・上の人・ほかの作業の人 | その人のもの | かぶり物の明るさで見分ける |

- 髪は、かぶり物をかぶっていても消さずに描きます。かぶり物の下から出る髪が、その人の目印になります。
- 例外は、髪を全部しまうかぶり物（衛生キャップ）です。このときだけ髪を描きません。

### 1-1. 服と役の印（下絵。11/3）

- 役の層の中身として、服と役の印の部品を `src/shared/picto/outfit.ts` に置いた。胴に重ねる服（作業着の上着・ポロシャツ・コックコート・白衣・給仕のベスト・反射のベスト・安全帯・前掛け・制服の上着・つなぎ・襟の無い上衣・救命胴衣・チェックのシャツ）、小物（ネクタイ・スカーフ・首の手ぬぐい・名札・腰袋・腕章・マスク・長靴・手袋・耳当て・ヘッドセット・顔の覆い・肩章・袖口の線）、かぶり物の印（線 0〜3 本・若葉）
- 袖・ズボン・長靴の明るさは部品ごとに変えられる。奥の足は手前より暗くする（6 節の光の向き）
- 業種ごとの役の姿の下絵は `src/shared/picto/industry-drafts.ts`（40 業種。docs/industries.md の業種と同じ番号）。参考の画像（画像を作る AI で作った、役が並んだ見本。実在の写真ではない）から、形と明暗で見分けられる印だけを拾った
- どれも Claude の下絵で、作者が Illustrator で直す。部品は g の id（part_…）に入れ、直したものを取り込めるようにした。並べた絵は `npx tsx scripts/picto-outfit.ts`
- 見習いの低いコック帽（chefLow）を、かぶり物の種類に足した

## 2. かぶり物

### 2-1. 種類の表

かぶり物には、種類ごとに次の 3 つを決めています。

- **明るさの決め方:** 役の明るさで塗る（role）か、いつも白（white）か
- **髪との重なり方:** 髪の上に載せる（show）か、髪をしまう（hide）か
- **頭のいちばん上の高さ:** 人を地面に置く位置を決めるのに使う

| 種類 | 職場の例 | 明るさ | 髪 | 頭のいちばん上 |
|---|---|---|---|---|
| helmet（安全帽） | 電気工事・建設 | 役の明るさ | 載せる | −116 |
| cap（つばの帽子） | 現場の上の人・物流 | 役の明るさ | 載せる | −112 |
| chef（コック帽） | 厨房・製菓 | いつも白 | 載せる | −158 |
| hygiene（衛生キャップ） | 食品の工場 | いつも白 | しまう | −100 |

- **覆いかぶさる大きさ:** かぶり物は、髪に覆いかぶさる大きさにします。
  - 縁は髪の横幅より外へ、てっぺんは髪より上へ出します。
  - 髪が見えてよいのは、縁より下（もみあげ・えり足）だけです。
  - お団子のように頭の上に出る髪は、かぶり物の中にしまいます（描きません）。
  - テスト（`tests/picto-headwear.test.ts`）で、髪 3 つ × かぶり物 × 3 つの向きの全部について、縁より上の髪がかぶり物からはみ出していないかを画素で調べます。
- **種類を足すとき:** 表に 1 行と、3 つの向き（正面・斜め・真横）の形を足します。形は、首の付け根を原点にした座標で描きます。顔は y −70〜0、髪の上は −90 です。
- **候補:** 三角巾、看護の帽子、防災ずきん、溶接の面など。

### 2-2. かぶる・外す（「かぶらないのはダメ」のカード）

- 同じ人で、かぶり物だけを `"none"` と種類の名前で入れ替えます。髪・顔・役は変えません。
- そうすると、「かぶっていない（ダメ）」と「かぶった（よい）」の 2 コマが、同じ人の話として読めます。
- ダメのコマには、禁止の印（赤）を足します。

### 2-3. 職場ごとの初めの値

- 職場（テナント）ごとに、役ごとのかぶり物の種類を決めておきます。
  - 例: 電気工事の職場では、新人＝白の安全帽、上の人＝黒のつばの帽子、ほかの作業の人＝灰色の安全帽。
- 絵の数字を決める AI は、かぶり物を毎回選びません。
  - かぶるかどうかは、場面ごとに「かぶる・外す」だけを決めます。
  - 種類は、職場と役から自動で決まります。

## 3. 役の見分け方

- **役の明るさ:** 新人 #fff、上の人 #222、ほかの作業の人 #999。この明るさを、かぶり物に塗ります。
- **いつも白のかぶり物（コック帽・衛生キャップ）:** 明るさで役を見分けられません。その職場では、下の「役の印」で見分けます。
- **かぶり物を外した場面:** その場面では、髪形と立ち位置で見分けます。

### 3-1. 業種ごとの役の段と印（11/3 作者が決めた方針。表は仮の案）

役の段と見分け方は業種ごとに違うので（料理長と副料理長、店長とホールの係など）、業種ごとに決まりを持ちます。詳しくは製品仕様 §14。

- **印に使う部品:** 色は使えないので、形と明暗で見分けます。
  - かぶり物の高さ、かぶり物の線（0〜2 本）
  - 腕章、首のスカーフ（明暗）
  - 服の種類（エプロン → ベスト → 上着）、ネクタイ
- **カードの役とのつなぎ方:** カードの役（新人・上の人・ほかの作業の人）を、業種の段のどれかに当てます。

| 業種 | 役の段（下から） | 見分ける印（仮） | 確かさ |
|---|---|---|---|
| 電気工事・建設 | 新人 → 作業員 → 職長 → 現場の監督 | 新人は若葉の印、職長は安全帽に線 1 本と腕章、監督は黒のつばの帽子 | 中 |
| 造船・工場の製造・林業 | 作業員 → 班長 → 職長 | かぶり物の線の本数、班長は腕章 | 低 |
| 自動車の整備 | 整備士 → 整備主任 → 工場長 | 工場長は上着 | 低 |
| 厨房 | 見習い → 料理人 → 副料理長 → 料理長 | コック帽の高さ。料理長は黒の上着かスカーフ | 中〜低 |
| 配膳・ホール・小売・宿泊 | 係 → 主任 → 店長（支配人） | エプロン → ベスト → 上着とネクタイ | 低 |
| 食品の工場・漁業・水産加工 | 作業員 → 班長 → 管理者 | 衛生キャップの線の本数、新人は腕章 | 低 |
| 介護 | 職員 → リーダー → 管理者 | そろいのポロシャツ。リーダーは上着 | 低 |
| 病院 | 看護助手 → 看護師 → 主任 → 師長 | 上衣の明暗と刺繍 | 低〜中 |
| ビルの清掃・物流倉庫・農業 | 作業員 → 班長（責任者） | 腕章か、かぶり物の線 1 本 | 低 |
| 警備 | 隊員 → 班長 → 隊長 | 肩章・階級章、制帽 | 中 |
| 自動車運送 | 運転する人 → 運行管理者 | 制帽は会社の決まり。管理者は上着 | 低 |
| 鉄道 | 駅員 → 助役 → 駅長（別に運転士） | 制帽の線の本数と太さ、袖の印 | 中 |
| 航空（空港の地上の係・整備） | 一般の係 → 責任者 | ベストの上下の切り替え（2 つの明暗） | 中 |
| ほかの 19 業種（溶接・クリーンルーム・縫製・解体・パン・畜産・漁船・リネン・リサイクルなど） | 業種ごと（製品仕様 §14） | 写真で決める | 未調査 |

- **調べた結果（11/3、ネットの記事）:** 業界全体で決まった印は、ほとんどありません。確かめられたのは、鉄道の制帽の線、空港のベストの色分け、警備の階級章、職長だけ帽子をそろえる会社の例、コック帽の高さだけです。ほかは会社・店ごとです。そのため、この表は初めの値にすぎず、主に使うのは下の会社ごとの決まりです。

- **会社ごとの決まりが先:** 同じ業種でも会社で違うので、キャラクターを作る最初の画面で、会社の決まり（例:「職長は線 2 本」「店長だけ黒いベスト」）を役ごとに入れられます。入れた決まりは、この表より先に使います。
- **確かめ方:** ネットの記事で埋め、作者が集める業種ごとの写真で確かめて直します。
- **部品の作り方:** Claude が下絵の SVG を出し、作者が Illustrator で直します（下絵 → 修正待ち → 描き終わり → 取り込み → 重ねて比べる）。

## 4. 顔と頭

- **顔:** 幅 90・高さ 70 の、角の丸い形です。
- **目・鼻・口:**
  - 目は小さな黒い楕円（4.6×5.8）です。
  - 鼻は点です。
  - 口は、やわらかく笑った短い線です。
- **線の太さ:** 顔も首も 5 で、体の縁と同じです。
- **首:**
  - 頭を 14 持ち上げて、短い首を見せます。
  - 首は胴より先に描き、付け根を襟の下に隠します。胴の上に描くと首の下の縁が見えて、首が切れて見えます。
- **向きごとの顔:**
  - 斜めでは、目・鼻・口と前髪の分け目を、顔の向く側へ寄せます。
  - 真横では、目は 1 つです。

### 4-1. 選べる顔と髪（下絵。11/4）

キャラクターを作る最初の画面で、ゲームの初めのアバターのように顔と髪を選べます。部品は `src/shared/picto/avatar.ts` と `character.ts` にあります。
- **選べるもの:** 輪郭 4（ふつう・丸・細い・四角）、目の形 5・大きさ 3、まつげ 3、眉 4、口 4、眼鏡 3、肌 2、ひげ 2、髪 19（おかっぱ・短い・お団子・ロング・ポニーテール・坊主・七三・くせ毛・ツーブロック・マッシュ・センターパート・オールバック・ショートボブ・三つ編み・ツインテール・スキンヘッド・ソフトモヒカン・ウルフ・ハーフアップ）。
- **向きで崩れない作り:** 目・鼻・口・眉は、向きごとの目印（顔の幅に比例）から描きます。髪は 3 つの向きを同じ作り（てっぺんと丈は同じ、分け目は顔の向く側へ）から描き、顔の幅に合わせて横だけ伸び縮みさせます。マスク・耳当て・顔の覆いも顔の幅に合わせます。
- **髪の形の出どころ:** おかっぱ以外の 18 種は、作者が参考絵の上で髪だけを手で塗り直した 3 つの向きの絵（透明つき・3 色）を、`scripts/picto-hair-trace.py` がパスにして頭の座標に合わせた形です（`src/shared/picto/hair-traced.ts`。手で直しません）。置く位置は、作者が髪を顔に載せて見せた見本（赤い髪）から求めます。黒は髪の色、#777 の灰（つやの線・剃った所）はそのまま重ね、坊主は黒い縁の内側を髪の色にします。斜め・真横は、見本の下絵の顔の前の線（あごから 30 上）をこちらの顔の線に合わせて置きます。前髪の出すぎなど、置いても合わない所だけ、パスにする前に頭の座標の上で直します（直す髪と向きはスクリプトの直しの表）。スキンヘッドの頭の丸みは見本の下絵の頭の形に合わせ、ソフトモヒカンは、頭の丸みの線をスキンヘッドと同じ 1 つの形で描いて顔の輪郭の線につなげ、元の絵からは剃った所の灰ととさかだけを使います。灰は頭の線の下に敷き（線が灰の端を隠す）、とさかは線の内側から雫の形に立ち上がらせます（線を横切る 2 点の弦から下へ半分の楕円を垂らす。深さは 3 つの向きとも 14 まで。てっぺんは 3 つの向きとも y −125）。頭の線の両はしは顔の輪郭の線の真っすぐな所に重ね、つなぎ目を出しません。耳は髪の上に重ねて描きます。あごより 8 下の髪は胴より後ろの層に入れます（三つ編みは胸の前）。かぶり物をかぶったときは、今までの手で描いた 8 つの形のうち近いものに替えます。
- **髪の直しの記録:** 作者の見直しで直してきた経過と、直す前に毎回やることは `docs/picto-hair-fixes.md`。
- **耳:** 正面は顔の縁から外へ出た半分、斜めは後ろへ回った見える耳 1 つ、真横は頭の真ん中の耳 1 つです。耳はどの髪でも髪の前の層の上に描き、マスクの紐と眼鏡の蔓は耳の裏へ入れて、掛かって見えるようにします。
- **画素のテスト:** 部品がどの向きでも顔からはみ出さない、眉が前髪に隠れない、かぶり物が 8 つの髪を全部覆う、真横で顔の前を越えない、髪の量とてっぺんが向きで変わりすぎない、色は灰色だけ。初めの値の絵は今までと 1 文字も変わりません（お団子の斜め・真横だけは、正面と同じてっぺんに描き直しました）。

## 5. 体と向き

- **向き:** 正面・斜め・真横の 3 つです。左向きは右向きを反転して作ります。
- **正面:** 立って向き合う場面だけに使います。
  - 胴と首は傾けません。手足の角度は、横へ開く向きとして読みます。
  - 歩く・倒れるのような前後の動きは、斜めか真横で描きます。
- **斜めの手前と奥:**
  - 右を向くと、体の右側がこちらを向きます。そのため、手前の腕と足は画面の左に置きます。
  - 手前の腕は、前へ振ると胸の上を横切ります。奥の腕は、後ろへ振ると胴の裏に隠れます。
- **ベストの V:**
  - 正面はまん中です。
  - 斜めは、胸の向く側へ寄せます。奥の辺は短く立てます（体の丸みで回り込むため）。
  - 真横は、さらに前へ寄せます。
- **描く順:** 奥の腕 → 奥の足 → 手前の足 → 首 → 胴 → 頭 → 手前の腕。
  - 正面では、両腕を体と頭のあとに描きます。
  - 手前の腕は、頭より上へ挙げても、頭と顔の前に描きます。
- **手足:**
  - 縁を全部描いてから、中身を全部描きます（2 回描き）。こうすると、ひじ・ひざの区切りの線が消えます。
  - 靴の口はすねに合わせ、靴底は床と平行にします。床と平行に戻す回転は ±25° までです。

## 6. 色と明暗

- **使う色:** 黒・白・灰色だけ（R=G=B）です。例外は、禁止の赤だけです。
- **光の向き:** 光はカメラの側から当たると考えます。手前ほど明るく、奥ほど暗くします。
- **手前と奥の明るさ:**

  | 部位 | 手前 | 奥 |
  |---|---|---|
  | ズボン | #7a7a7a | #333 |
  | 靴 | #3a3a3a | #151515 |

- **正面:** 両足ともカメラから同じ遠さなので、左右とも手前の明るさで描きます。
- **服:** 袖・シャツ・手・顔・首は白、ベストは #ccc、帯は #333 です。
- **髪:** 黒（#000）です。かぶり物が無いときだけ、つやの線（#777）を足します。
- **強調:** 色では強調しません。線の太さ・大きさ・明暗・枠で出します。

## 7. 本番に切り替えるときにそろえる所（履歴。11/5 に切り替え済み）

11/3 に書いた手順のまま残す。今の描き方は、上の節と `docs/decisions.md` の 11/5 の節を見る。

- **絵柄の検査（`style.ts`）:** 今の決まりでは、白は「新人のヘルメット・背景・吹き出し」の中にしか使えません。新しい絵柄は、顔・腕・シャツ・首・手と、いつも白のかぶり物で白を使います。そのため、`data-part` の印で白を使ってよい部位を足します。
- **計画（`plan.md` の 1b）と決定の記録（`decisions.md`）:** 役の見分け方と、奥の足の明るさ（前は「奥を明るく」）を、この文書に合わせます。
- **絵の数字を決める AI への指示（`draw.ts`）:**
  - かぶる・外すを、場面ごとに選べるようにします。
  - 正面の使いどころを書きます。
- **本番の描画（`scene.ts`）:** 前の人形（`skeleton.ts`）から、この描画に替えます。
  - かぶり物は、小物（props）ではなく、人の層として描きます。
  - 「※取り直し」の録画は撮り直します。
