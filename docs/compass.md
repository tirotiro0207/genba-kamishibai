# 軸（コンパス）

このプロダクトがどこから出て、どこへ向かうかを、1 本のベクトルとして書く。迷ったらここに戻る。

## 1. 始点（前提）

- 現場のルールや安全の決まりは、**文字の資料**と、**ベテランの頭の中**にある
- 外国籍の新入社員には、日本語の文字ではそれが届かない
- 教える側にも、伝わる教材を作る時間がない
- 使う人: 現場の教育担当・ベテランの職人・現場監督・外国籍の新入社員

## 2. 終点（どこに届くか）

- 日本語の文字が読めなくても、**絵のカード**で「守ること」と「その理由」が分かる
- 新入社員に届くのは、会社の監修者が直して**署名したカードだけ**

## 3. 終点の先（将来）

- 業界: 電気工事から始めて、建設・製造・介護など、外国籍の人が働くほかの業界へ
- 言葉: ベトナム語から、英語・クメール語へ
- 使うほど、その会社の言い方を覚えていく

## 4. 変化の質

- **自然な言葉や文章が、絵になる**
- 話した言葉や資料の文章が、ピクトグラムのカードに変わる
- カードは紙芝居のように 1 枚ずつ送って見せる。画面も、切り替えるたびに紙芝居の絵を抜くように動く

## 5. 変化の量

- **膨大な情報が、ピクトグラムに収束する**
- 見る人が受け取る量は減るが、情報は失わない
- 絵は情報を折りたたんだもの。開けば、絵のどの部品が元の文のどこに当たるかの**経路**がある
- だから、どのカードも元の文に必ず戻れる

---

1 行で: 文字と頭の中にあった現場の決まりを（始点）、情報を失わずに絵へ折りたたみ（質・量）、署名されたカードとして新入社員に届ける（終点）。そこから業界と言葉を広げ、会社の言い方を覚えていく（終点の先）。
