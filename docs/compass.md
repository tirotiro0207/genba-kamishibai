# 軸（コンパス）

このプロダクトがどこから出て、どこへ向かうかを、1 本のベクトルとして書く。迷ったらここに戻る。

## 1. 始点（前提）

- 現場のルールや安全の決まりは、**文字の資料**と、**ベテランの頭の中**にある
- 外国籍の新入社員には、日本語の文字ではそれが届かない
- 教える側にも、伝わる教材を作る時間がない
- 使う人: 現場の教育担当・ベテランの職人・現場監督・外国籍の新入社員
- 事故は、慣れて自信がついたところから過信に変わる際で起きる。新入社員だけの話ではない（11/6 の聞き取りから）

## 2. 終点（どこに届くか）

- 日本語の文字が読めなくても、**絵のカード**で「守ること」と「その理由」が分かる
- 新入社員に届くのは、会社の監修者が直して**署名したカードだけ**
- ベテランは決まりを「頭の中に持つ側」（始点）であると同時に、カードを**読む側**でもある。朝礼で同じカードを読み、自分の慣れを確かめ直す（11/6 の試しで、ベテランの職人が「朝礼で使いたい」と言った）
- カードは画面だけでなく、**作業の場所に貼って置く**。画面で読むのと、その場で目に入るのとの二重の対策にする

## 3. 終点の先（将来）

- 業界: 電気工事から始めて、建設・製造・介護など、外国籍の人が働くほかの業界へ
- 言葉: 訳は作らず、**やさしい日本語のまま**、ふりがなと絵でほかの言葉の人にも届ける。国籍が増えても（11/6 の試しは 4 か国）、絵とやさしい日本語で同じカードを使う（11/5 の決定。監修者が読めない訳には署名できないため）
- 使うほど、その会社の言い方を覚えていく

## 4. 変化の質

- **自然な言葉や文章が、絵になる**
- 話した言葉や資料の文章が、ピクトグラムのカードに変わる
- カードは紙芝居のように 1 枚ずつ送って見せる。画面も、切り替えるたびに紙芝居の絵を抜くように動く
- 質とは「伝わるか」。絵にすること、危ない読み違いを止める安全網、監修者と新入社員の声で直すこと、の 3 つで上がる

## 5. 変化の量

- **膨大な情報を、失わずにピクトグラムへ折りたたむ**
- 見る人が一度に目にする量は減るが、カードが持つ情報は元の文と同じ（カード ≈ 元の文）
- 絵は情報を折りたたんだもの。開けば、絵のどの部品が元の文のどこに当たるかの**経路**がある
- だから、どのカードも元の文に必ず戻れる
