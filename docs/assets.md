# アセット（小物・服・表情）の差し替えの決まり

会社（テナント）ごとに、Claude で直して差し替えられる物は 3 つ。どの会社がどう変えても絵が成り立つように、**差し替えられる所を枠で決める**。
決まりの本体は `src/shared/picto/asset-rules.ts`。描く側（`outfit.ts`・`avatar.ts`・`props.ts`）と API（`src/worker/assets.ts`）は、そこだけを見る。

| 部類 | kind の名前 | 差し替えの中身 | 直すモデル |
|---|---|---|---|
| 小物 | 今のまま（`first_aid` など） | 0〜100 の正方形に描いた SVG 1 枚 | `ASSET_MODEL`（上のモデル） |
| 服 | `wear_` + 服の名前（`wear_chef_jacket`・`wear_business_suit`） | 3 つの向き（front・quarter・side）全部の SVG | `ASSET_MODEL` |
| 表情 | `face_` + 表情の名前（`face_anger`） | 決まった部品の組み合わせ（JSON） | `ASSET_FACE_MODEL`（下のモデル） |

## 1. kind の名前

どれも `[a-z0-9_]+`。部類は頭の文字（`wear_`・`face_`）で分け、小物の名前はこの 2 つで始めない。登録は 1 か所（`prop-override.ts`）で、`/active` は部類によらず `{ overrides: { kind: 文字 } }`。服は 3 つの向きを JSON の文字に、表情は組み合わせを JSON の文字にして入れる。

## 2. 色は灰色（R=G=B）に直す

どの部類も、差し替えの SVG の `fill` と `stroke` は、保存の前（`cleanAssetSvg`）に灰色へ直す。まず使ってよい要素と属性だけに絞り（`sanitizePropSvg`）、そのあと明るさ（0.299 R + 0.587 G + 0.114 B）を保った灰色の `#rrggbb` にする。`none` と `TONE`（下）はそのまま、読めない色は `#808080`。

## 3. 服

- 差し替えは 3 つの向き全部が要る。1 つでも形が無ければ 502（「直した服に形が無い向きがあった」）。
- 胴の座標のまま描く（原点＝腰、胴の上の端 −142・下の端 20）。Claude には、元の 3 つの向きの SVG のコードを、枠の `viewBox` のまま渡す。
- 見せる枠は向きごとに決まっていて、胴の幅（片側。正面・斜め 46、真横 30）より左右に 20 ずつ広く、y は −175〜140。今の 22 の服を全部描いて端を測ると、x は正面・斜めが −66〜66（空調服のファン）、真横が −50〜39、y は −145〜121（長い前掛けの裾）で、どれも収まる。描くときは、id を使わずに枠で切れるよう、入れ子の `<svg x y width height viewBox overflow="hidden">` で包む。枠の外は描かれない。
- 服の明るさ（tone）は、差し替えの中の色の名前 `TONE` を、描くときにその服の tone に置き換える。
- 重なりの順は元の服と同じ場所（`part_…` の層）。体・腕・脚・顔は元のまま描き、入れ替わるのは胴の服の層だけ。

## 4. 表情

差し替えは SVG ではなく、部品の組み合わせ。どの顔の形・大きさ・向き・傾き・眼鏡・ひげと組んでも成り立つ。

```json
{ "eyes": "open", "brows": { "inner": -43.5, "outer": -50 }, "mouth": "shout", "mouthWidth": 1 }
```

- `eyes`: `open`（顔の部品で選んだ目）・`closedArc`（閉じて上へ丸い弧）・`pinched`（強く閉じた「＞ ＜」）・`wide`（丸く見開く）
- `brows`: `own`（顔の部品で選んだ眉）・`raised`（丸く上げた眉）・`{ inner, outer }`（鼻の側の端と外の端の y。−54〜−42）
- `mouth`: `smile`・`openSmile`・`shout`・`frown`・`flat`・`smallO`・`wave`・`clench`
- `mouthWidth`: 口の横幅の倍率。0.6〜1.4。どなる口（`shout`）だけは 1.25 まで（全部の顔の形・大きさ・向きで描いて測ると、これより広げると真横の下の角が輪郭の外へ出る）

数は全部決まった幅に収め、知らない値は既定（`open`・`own`・`smile`・1）に戻す。今の 9 つの表情は、この組み合わせで描いて、組み替える前と 1 文字も変わらない（`tests/asset-face-same.test.ts`）。話す口（あいうえお）は今までどおり表情の口より先で、寝ている絵は（差し替えた）pain を使う。

## 5. API

`/api/t/:tenant/assets`。一覧の各行に `group`（`prop`・`wear`・`face`）と日本語の名前が付く。署名済みのカードの枚数は、小物は `"kind"`、表情は `"expression"` で数え、服は数え方が決まっていないので `null`（画面は「どのカードの人にも効く」と出す）。直す（`POST /:kind/fix`）は部類ごとに system と出力の型が違い、版・決める（`POST /:kind/choose`）・戻す・画像は部類によらず同じ。版は追記だけ。
