# 動画の作り方の記録

3 分の動画を、どう作ったかの記録。1 回の作業ごとに 1 項目足す。台本と画面の流れは docs/video.md の「台本 v2」、短い 1 行の記録は docs/build-log.md。
書き出したもの（mp4・静止画）は git の外（private/material/）に置く。

## 作者の決定（11/5）

1. 制作の記録を最初から残す。理由: できた動画だけでなく、作り方も後から見せられる形にしたいため。後から思い出して書くと、理由と数字が抜ける
2. 台本は v2 に替える（流れは docs/video.md の「台本 v2」）。前の下書き（098b）と仮の 3 分版（098）は消さずに残す。理由: どう変わったかを記録に残し、前の版の録画も使い回すため
3. 画面の作りは、上に紙芝居の木の枠、下に人物が並んで左右に歩く。地は紫。折り紙の動きは 3 回使う（0:05 紙 → 人、1:12 資料 → 1 枚・0 字、2:45 業種の紙 → カード）。理由: 同じ動きを繰り返して、最後に意味を広げる
4. 道具は Remotion。置き場はリポジトリの中の video/。アプリのピクトグラムの部品（src/shared/picto）をそのまま読み込んで描く。理由: アプリの絵と同じ部品で動かせば形が崩れず、ピクトグラムの直しが入っても書き出し直すだけで動画に入る
5. 動画の生成 AI は使わない。作者が Remotion の出来を見て、うまくいかないカットだけ替えると決めたら、そのとき費用を出して作者に聞く。理由: 先に Claude だけで作ってみたい（作者）。クレジットはお金なので
6. 冒頭の 15 秒は場面ごとに 1 つの Composition にし、最後に 1 本につなぐ。時計は数を出さず針の動きだけ。効果音はまだ入れない。理由: 場面ごとに直し・撮り直しができる。作りものの数を本物に見せない。使ってよい条件の音源を選ぶのは後で
7. 人の名前・会社の名前は、動画にも文書にも出さない。案内人は実在の方がモデルなので、公開の前に本人の OK を取る（作者が取る）
8. ポータル（0:35〜0:39）の真ん中に、会社の印を入れる（許可待ち・素材は git の外）。素材が無いときは、自分で描いた円と稲妻の一般的な印を出す。印の形と色は変えない
9. 紙は 1 枚ずつ印刷して出し、手本の手順どおりに全部折る（11/5 の直し）。脚の紙（1 枚目）→ 体の紙（2 枚目）→ 組む。1 手順は 0.12〜0.15 秒。紙の人の文字の柄は胴の前だけに薄く、手足は無地。理由: 手本の折り紙は同じ大きさの正方形 2 枚で作る。手順を飛ばさずに見せると、文書の紙が折られて人になったことが嘘のない形で伝わる。全身に横線があると包帯に見える
