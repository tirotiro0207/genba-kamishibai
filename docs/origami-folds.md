# 冒頭の折り紙の手（本当に折る版・v5）

動画の冒頭（0:04〜0:07）で見せる折り紙の手。コードは `video/src/fold-steps.ts`、折る仕組みは `video/src/fold.tsx`、動きは `video/src/intro.tsx`。
紙は 200 の正方形を 45° 回した菱形（半分の対角 141.4）。真ん中が (0, 0)、y は下が正。1 手は 0.4 秒（12 コマ）。左右で同じ手は 1 手にまとめて同時に折る。
どの手も「紙を折り線で 2 つに分け、動く側を折り線を軸に 0°→180° 回して倒す」。90° を越えると裏の面が見え、回っている間は下に影が落ちる。
「折り込む」は、向こうへ倒した所が紙の間に入って見えなくなる手（手本の折り込み・中割りを、外から見た形で見せる）。

## 大きい手の順

正方形 → 回して菱形にし、裏返す → 対角線の三角（折り筋） → 細長い六角・凧 → 脚が分かれる → 腕が出て垂れる → 頭が出る → 体を脚に差し込む → はめる。
2 枚とも、刷った面を向こうにして置く。折り返したフラップにだけ刷った字が出るので、字は胴と脚の面に残り、頭と腕は無地になる（裏返った字も出ない）。

見せる手は 12 手（脚の紙 4・体の紙 6・組む 2）。体の紙は脚の紙から 1 手半（0.6 秒）遅れて折り始める。

## できあがりの形（紙の人の形の正本）

手本の「できあがりの形」の輪郭 20 点（幅 : 高さ = 0.46 : 1、時計回り）を、箱の (u, v) → 紙の人の座標 ((u − 0.46) × 185.5, −25 + (v − 0.22) × 403.2) で置き、折り線をこの点に合わせた。

|---|---|---|
| 頭の上 | (.30,.01) (.61,.01) | (−29.7,−109.7) (27.8,−109.7) |
| 頭の横 | (.67,.09) (.66,.15) | (38.9,−77.4) (37.1,−53.2) |
| 首 | (.55,.20) | (16.7,−33.1) |
| 肩 | (.82,.22) | (66.8,−25) |
| ひじ・腕の先 | (.93,.35) (.97,.58) | (87.2,27.4) (94.6,120.2) |
| 腰・足 | (.82,.80) (.82,.98) (.56,.97) | (66.8,208.9) (66.8,281.4) (18.5,277.4) |

折り終えた形を測った値（`video/src/fold-steps.ts` の手で折った面から）: 頭の幅 77.8 ÷ 肩幅 134.3 ＝ 0.58（手本 0.6）、全体の幅 177.8 ÷ 高さ 391.1 ＝ 0.455（手本 0.46）。

## 組む

| 手 | 手本の手 | 何をするか |
|---|---|---|
| J1 ◎ | J1 | 2 枚が紙の人の場所へ寄り、体の紙（手前）を脚の紙（奥）に上から差し込む。体の下の角が脚の紙の上から 0.37 の所まで重なる |
| J2 ◎ | J5 | パチンとはまる（小さく光る）。そのあと目が描かれ、腕（肩を軸）と脚（股を軸）がぴょこっと動く |

紙の人の部品は、折り終えた面そのものを切り分けたもの（胴と頭・両腕・両脚）。腕は肩 (±68.9,−25) を軸に回して上げ下げする（垂らした形が 0°）。
