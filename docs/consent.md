# 同意書（026）

現場の確認の日（新入社員がカードを見て答える日）の前に、参加する人に読んでもらう同意書を用意した。

- 言葉: 渡すのはやさしい日本語の版だけ（11/4 作者の決定）。ベトナム語の下書きは置き場に残すが使わない。読めないところは、当日に作者が口で説明して質問を受ける。言葉を足すときは、同じ項目で言葉ごとに 1 ファイル
- 置き場: `private/consent/`（git に入らず、GitHub に上げない）。リポジトリには項目の一覧と検査だけを置く
- 検査: `tests/consent.test.ts` が、置き場にある全部の言葉で、項目が全部・順番どおりに入っているか、会社の名前・連絡先・名前を書く欄が無いかを調べる
- 確認: やさしい日本語の版を作者が確かめる。ベトナム語の版は渡さないので、確認は頼まない

## データの持ち主（11/6 作者の決定）

直しと署名の記録は二段に分けて扱う。

| 何か | 持ち主 | ほかの会社に使うか |
|---|---|---|
| ① 会社の中身: 決まりの文・現場の言葉・誰がいつ何を直して署名したか | 登録した会社 | 使わない。作者の会社は預かって保存するだけ |
| ② 絵の直し方: 「この姿勢は逆に読まれた」「禁止の印はこの位置だと読める」 | 会社の文・会社名・個人名を外した形 | 会社が「使ってよい」を選んだときだけ、共通の描き方（姿勢と部品の決まり）に戻す。最初は「使わない」 |

- 自分で立てて使う場合（このリポジトリを自分の Claude の MCP や API で動かす）は、データは全部その会社の手元に残り、作者の会社には何も来ない
- 共通の描き方に戻したときは、どの会社から来たかを伏せて、いつ・どの部品を・どう変えたかを公開の変更履歴に残す
- 解約のときは、書き出してから消せるようにする。消したことも記録に残す

今の作りとの関係（書いた文がうそにならないように）:

- 「使ってよい」を選ぶ設定はまだ無い。今は全部の会社が「使わない」のまま
- 次のカードの下書きに渡す手本（前の直し・署名済みのカード・会社の言葉）は、同じテナントの同じカテゴリからだけ集める。ほかの会社のものは集めない（`src/worker/exemplars.ts`。テスト `src/worker/exemplars.test.ts` の「同じ会社・同じカテゴリの直近の直しと署名済みのカードだけを集め、件数の上限を守る」「作成の指示に同じ会社の手本が入り、ほかの会社の差分は入らない」）
- 消す: テナントを最初の状態に戻すと、そのテナントのカード・答え・採点・言葉・手本の記録が消え、戻したことは消せない記録（resets）に残る。監査の記録は消さずに、連鎖を新しく始める
- 書き出す: 今あるのは、カードの絵（PNG / SVG）と、名前を消した答えの CSV。テナントの全部を 1 度に書き出す仕組みはまだ無い
