# 同意書（026）

現場の確認の日（新入社員がカードを見て答える日）の前に、参加する人に読んでもらう同意書を用意した。

- 言葉: やさしい日本語とベトナム語。新入社員の国籍が決まったら、同じ項目で言葉を足す（言葉ごとに 1 ファイル）
- 置き場: `private/consent/`（git に入らず、GitHub に上げない）。リポジトリには項目の一覧と検査だけを置く
- 検査: `tests/consent.test.ts` が、置き場にある全部の言葉で、項目が全部・順番どおりに入っているか、会社の名前・連絡先・名前を書く欄が無いかを調べる
- 確認: ベトナム語は、ベトナム語の分かる人に確認を頼む（まだ送っていない）

## 項目

| 印 | 書いてあること |
|---|---|
| purpose | 何をするか（カードの意味が分かるかを確かめる。本人のテストではない。約 30 分） |
| voluntary | 参加は自由。参加しなくても困ることは無い |
| no-boss | 確かめる場に上司はいない |
| stop-delete | いつでもやめられる。やめたら答えを消す。あとから頼まれても消す |
| not-to-company | 誰がどう答えたかを会社に渡さない |
| not-evaluation | 仕事の評価やお金に使わない |
| recording | 顔と声は撮らない。撮るのは手元と画面だけ |
| publish-anonymous | 公開するのは、名前を消した答えだけ（名前の代わりに番号） |
| reuse | 答えはカードを良くするために使う。日本語に訳したり採点したりするために AI（Claude）に渡すことがある。それ以外の目的では外のサービスに渡さない |
| questions | 分からないことはいつでも聞ける |
| sign | 読んで分かったら印を付ける。日付と番号だけで、名前は書かない |
