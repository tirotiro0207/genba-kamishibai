# 電気の現場の小物 21 品目（11/5）

電気の現場でよく使う道具と保護具を、写真の比率だけを手がかりに、`docs/picto-design.md` の決まりで描きます。
写真はなぞらず、会社名・製品名・ロゴ・メーカーの色は描きません。写真はリポジトリに入れません。

- **区分:** 新 = 新しい名前、使う = 今の名前のまま、描き直し = 今の名前で形を変える
- **置き方:** 着る = 人に着せる絵（`outfit.ts` の項目）と、物だけの絵の 2 つ。置く = 床・壁・手に置く
  - 場面の絵（カードのコマ）では、人に着ける小物（頭・手・足・体に付くもの）は、その人の服とかぶり物（outfit）として描きます。`propsSvg` の着けたときの描き方と、安全帯の肩とももの帯（`harnessStraps`）は、`propsSvg` を直接呼ぶとき（`scripts/export-props.ts` とテスト）だけ使います（120）
- **付く所:** `DEFAULT_JOINT`（関節）か、床（`ON_FLOOR`）・壁・キャンバス
- **業種:** `docs/picto-design.md` 9 節の表の番号

## 形の手がかり

- `aed`: 取っ手の付いた箱に、ハートと稲妻と「AED」の字（字は線で描く。11/5 作者の判断）
- `cubicle`: 灰色の屋外の箱に扉 3 枚・上の換気口・下の台
- `work_platform`: 平らな天板を 4 本の脚で支え、脚の間に横の桟。片側に手すり
- `rolling_scaffold`: 枠を 2 段に積み、斜めの筋かい・中の踏みさん・下の車輪・上の手すり
- `step_stool`: 低い箱の踏み台（天板と、横の持ち手の穴）
- `voltage_detector`: ペンの形の軸、細い先、頭の光る窓
- `insulated_gloves`: ひじの近くまでの長い袖口 / `cut_gloves`: 薄い手袋で、指先から手のひらが濃い
- `insulated_boots`: ひざ下までの筒と、口の帯 / `safety_shoes`: 短い靴と、つま先の芯の線
- `cooling_vest`: 作業着の上着に、腰の後ろの丸いファン 2 つ
- `armband`: 二の腕の帯に、小さい十字の印。写真の字は入れない
- `dust_mask`: 口を覆う面体と、その両側の丸いフィルター
- `power_drill`: ピストルの形（握り・下の電池・前のドリルの刃）
- `crane`: 車体と長いブーム、先からのワイヤーとフック。吊り荷（`suspended_load`）を先の真下に置くとワイヤーがつながる
- `aerial_platform`: シザーの腕と、手すりの付いたかご、下の車体と車輪

## 作者が決めたこと（11/5）

- AED の箱に「AED」の字を入れる（線で描く）
- 腕章の印は小さい十字のまま
