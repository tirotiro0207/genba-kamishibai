# 動画の作り方の記録

3 分の動画を、どう作ったかの記録。1 回の作業ごとに 1 項目足す。台本と画面の流れは docs/video.md の「台本 v2」、短い 1 行の記録は docs/build-log.md。
書き出したもの（mp4・静止画）は git の外（private/material/）に置く。

## 作者の決定（11/5）

1. 制作の記録を最初から残す。理由: できた動画だけでなく、作り方も後から見せられる形にしたいため。後から思い出して書くと、理由と数字が抜ける
2. 台本は v2 に替える（流れは docs/video.md の「台本 v2」）。前の下書き（098b）と仮の 3 分版（098）は消さずに残す。理由: どう変わったかを記録に残し、前の版の録画も使い回すため
3. 画面の作りは、上に紙芝居の木の枠、下に人物が並んで左右に歩く。地は紫。折り紙の動きは 3 回使う（0:05 紙 → 人、1:12 資料 → 1 枚・0 字、2:45 業種の紙 → カード）。理由: 同じ動きを繰り返して、最後に意味を広げる
4. 道具は Remotion。置き場はリポジトリの中の video/。アプリのピクトグラムの部品（src/shared/picto）をそのまま読み込んで描く。理由: アプリの絵と同じ部品で動かせば形が崩れず、ピクトグラムの直しが入っても書き出し直すだけで動画に入る
5. 動画の生成 AI は使わない。作者が Remotion の出来を見て、うまくいかないカットだけ替えると決めたら、そのとき費用を出して作者に聞く。理由: 先に Claude だけで作ってみたい（作者）。クレジットはお金なので
6. 冒頭の 15 秒は場面ごとに 1 つの Composition にし、最後に 1 本につなぐ。時計は数を出さず針の動きだけ。効果音はまだ入れない。理由: 場面ごとに直し・撮り直しができる。作りものの数を本物に見せない。使ってよい条件の音源を選ぶのは後で
7. 人の名前・会社の名前は、動画にも文書にも出さない。案内人は実在の方がモデルなので、公開の前に本人の OK を取る（作者が取る）
8. ポータル（0:35〜0:39）の真ん中に、会社の印を入れる（許可待ち・素材は git の外）。素材が無いときは、自分で描いた円と稲妻の一般的な印を出す。印の形と色は変えない

### 11/5 14:00〜14:40 冒頭の 0:00〜0:17 の 1 版目

- やったこと
  - Remotion の使ってよい条件を公式の文書で確かめた（docs/decisions.md に URL つき）
  - video/ に Remotion を入れた
  - 7 場面を 1 つずつの Composition にして書き出し、ffmpeg で 1 本につないだ
  - 場面: 時計の比べ / 印刷 / 折り紙 ① / 名のり / 枠を引っぱる / 開演 / 題
- なぜそうしたか
  - 紙の人は、ピクトグラムの骨格の関節の位置（poses.ts の stickJoints）を、折った紙の帯と六角の頭で描いた。姿勢は poses.ts の stand・wave・walk・pull・run をそのまま読む。歩く・走るは、手前と奥の手足を入れ替えた姿勢との間を行き来させて 1 歩にした
  - 折り紙は、上の正方形（腕と頭）と下の正方形（脚）の 2 枚の多角形で 8 コマを描いた。コマの間は、多角形を同じ点の数（64 点）に並べ直してから点ごとに動かす。紙の面の絵（ぼかした文字の貼り紙）は同じ座標に貼ったままなので、折れるたびに一緒に切り抜かれる
  - 8 コマ目で立ったら、骨格で描く紙の人に入れ替える（同じ大きさで重ねて薄く入れ替える）。そのあとは姿勢を変えて動かせる
  - 紙の人の体では、紙の赤い見出しが胸に来るようにずらした。頭に来ると口のように見えたため
  - 時計の色はアプリの時計（src/shared/clock-laps.ts の色）をそのまま読む。カードの針が先に止まり、濃い緑の太い針になる。文書の針は回り続け、1 周を越えると前の周を下に塗る
- 使った道具と命令
  - Remotion 4.0.536（2026-10-16 の版）
  - ブラウザは手元の Chrome
  - 書き出し: `cd video && node render.mjs`（場面を選ぶときは `node render.mjs s3-origami`）
  - 下見: `cd video && npm run studio`
- 出たもの（git の外）: `private/material/2026-11-05-冒頭/`

  - 折り紙の手本の一覧は、このリポジトリの守りのフックで開けなかった（読んでよい場所の外）。手本を見ずに、カンペの折り方の文から形を起こした。手本と見比べて形を直すかは作者が決める
